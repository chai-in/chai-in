# Private work at Tibcon

I built private applications for Tibcon from scratch and carried them through changing requirements, multiple scope changes, and complete rebuilds of major components. The work spans the first useful implementation, interface design, backend services, data migrations, deployment, and ongoing maintenance.

## What I built

| Project | Focus | Status |
| :--- | :--- | :--- |
| **Tibcon CRM** | Customer and internal business workflows, with the interfaces and services needed to support them. | Current private project |
| **Shared authentication** | A common sign-in foundation for Tibcon applications. | Current private project |
| **Tibcon Sentry** | Internal device-management tooling. | Retired; repository archived |
| **Tibcon Portfolio** | Internal portfolio-data tooling. | Retired; repository archived |

## From a narrow starting point to broader systems

The CRM began with an integration for bringing interaction data into the system. Its scope grew into a broader business application, with more workflows and supporting interfaces. Shared authentication became a separate foundation for multiple applications.

As requirements changed, the work included revisiting application boundaries, replacing storage paths, migrating data, and rebuilding interface and backend components. These were changes to how the systems worked, alongside the visible features.

## Rebuilding as the scope changed

I took these projects through iterations where extending the original implementation was no longer enough. That meant replacing major components, checking the new behavior, and continuing to maintain the application after the change.

The experience includes deciding when to keep an existing design, when to rebuild it, and when to retire a project. Sentry and Portfolio are earlier work rather than currently maintained products.

The source, operational details, and business data remain private. The descriptions here explain the work at a high level; the [public projects on my profile](https://github.com/chai-in) provide code and documentation visitors can explore directly.
